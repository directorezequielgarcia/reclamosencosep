# Roles institucionales, Notas y Capacitación

## 1. Tableros institucionales por ámbito
Cada perfil ve **información para la toma de decisiones según su ámbito**:

- **Autoridad de Aplicación**: reportes + **expedientes** (los que arma el Ente) +
  **recomendaciones de aplicación de sanciones** + normativa del vínculo
  ENCOSEP–Autoridad de Aplicación.
- **Concejo Deliberante**: reportes (indicadores, encuestas, problemas por
  barrio/servicio) + normativa + **agenda** + **presentar nota** + asistencia
  técnica.
- **Intendencia / Poder Ejecutivo Municipal (PEM)**: lo mismo que el Concejo.
- **Team ENCOSEP**: ve todo (ya tiene el panel admin).

## 2. Sección de Notas (comunicación con organismos)
El Ente se comunica con organismos **por medio de notas**, que pueden ser
**digitales**.
- Modelo Nota: emisor (ENCOSEP / perfil), destinatario (organismo), asunto,
  cuerpo, fecha, adjuntos, estado (borrador/enviada).
- Cada perfil institucional puede **presentar una nota** al Ente y el Ente a
  ellos.

Una sección **visible**, con un apartado **por cada tipo de usuario**:

- Modelo Capacitacion: título, descripción, videoUrl, módulo, dirigidoA (rol).
